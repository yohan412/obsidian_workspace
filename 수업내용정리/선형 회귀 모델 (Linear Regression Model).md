
## 회귀 모델 (Regression Models)

### 정의

- **목적**: 하나 이상의 설명 변수(독립 변수) $x$와 종속 변수 $y$ 간의 관계를 모델링
- **형태**:
    - 선형 회귀 (왼쪽 그래프): 직선 형태로 데이터 예측
    - 비선형 회귀 (오른쪽 그래프): 곡선 형태로 더 복잡한 관계 모델링 가능

![](https://i.imgur.com/1H7nk4p.png)

### 수식 표현 예시

**선형 회귀 모델 :**
$$
y = w_1 x + w_0
$$

**비선형 회귀 모델 예시 (다항 회귀) :**
$$
y = w_2 x^2 + w_1 x + w_0
$$

| 모델 종류     | 설명               | 수식 예시                          |
| --------- | ---------------- | ------------------------------ |
| 단순 선형 회귀  | 1개 변수, 직선        | $y = w_1 x + w_0$              |
| 단순 비선형 회귀 | 1개 변수, 곡선        | $y = w_2 x^2 + w_1 x + w_0$    |
| 다중 선형 회귀  | 다수 변수, 선형 조합     | $y = w_1 x_1 + w_2 x_2 + w_0$  |
| 다중 비선형 회귀 | 다수 변수 + 비선형 항 포함 | $y = w_1 \sin x_1 + w_2 x_2^2$ |

## 오차 함수 (Error Function)

### 목적
실제값과 예측값의 차이(오차)를 최소화하는 $w_0, w_1$​을 찾는 것

## 수식 설명

1. **기본 표현**
$$
E(w_0, w_1) = \sum_{i=1}^{n} \left(y^{(i)} - \hat{y}^{(i)}\right)^2
$$
2. **선형 모델을 대입한 형태**
$$
E(w_0, w_1) = \sum_{i=1}^{n} \left(y^{(i)} - (w_1 x^{(i)} + w_0)\right)^2
$$

![](https://i.imgur.com/jDHTYcP.png)
- 검정 점: 실제 데이터 (actual values)
- 빨간 선: 모델이 예측한 직선 (predicted values)
- 세로선: 예측값과 실제값의 차이 → **오차(residuals)**
- 이 오차의 **제곱합**을 최소화하는 것이 목표입니다.

## 최적화 문제 해결 방법

### 1. 해석적 해 (Analytical Solution)

- **정의**: 문제를 수학적으로 명확히 공식화하여 **정확한 해(exact solution)** 를 계산하는 방법입니다.
- **예시**: 정규방정식(Normal Equation)을 이용한 선형 회귀 해법
- **장점**:
    - 수학적으로 명확하고 정확한 해를 구할 수 있음
    - 계산이 빠름
- **단점**:
    - 데이터가 크거나 복잡하면 계산 불가능한 경우도 있음


### 2. 수치적 해 (Numerical Solution)

- **정의**: 해를 직접 구하기 어려울 때, 반복적인 시도와 오차 허용을 통해 **근사 해(approximate solution)** 를 구하는 방법
- **대표 방법**: 경사 하강법(Gradient Descent)
- **특징**:
    - 메모리에 모든 데이터를 올리기 힘든 경우에 유리
    - 정확한 해가 아닌 **충분히 좋은 해**를 찾는 데 목적
    - 해를 찾는 과정에서 `추정(guess)`과 `검증(test)`을 반복
